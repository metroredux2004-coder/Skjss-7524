# Molecular Lab — Design

Supplied editorial biotechnology image is inspiration only: ivory/deep-teal contrast, fine rules, light typography, generous spacing; no copied text.

## Palette and typography
Ivory #f4f5ef, deep teal #103c43, ink #0a2d34, mint #b8d5c5 elastic, amber #e8b475 inelastic. Poppins body/light display with monospace instrument labels. Square panels and fine borders, not a generic rounded-card grid.

## Layout and behavior
Ivory editorial navigation and introduction over deep-teal lab, paired molecular chambers, horizontal controls, paired charts, then pale findings/methods. Stack on mobile. Accessible controls, keyboard focus and pauseable animation. No stock images: particles and scientific charts carry the visual.

## Architecture
Web only; React, canvas and shared deterministic TypeScript engine. No API routes or tables needed. Physics engine supports offline measured experiments, prompt/report/data downloads. Temperature and restitution reset paired initial states; thermostat, trails, presets, single-step, CSV export.
